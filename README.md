## 📖 简介

为 AstrBot 提供《骑马与砍杀：战团》联机服务器查询。默认关注骑砍中文站 `CN_X1`、`CN_X3_GK`、`CN_X4`，并直查 `CN_YJMD_X1/X2` 所在的两个固定端点；也可以按名称寻找其他服务器。

**有缓存时立即返回，数据较旧时标明时间。** 首次或未知名称查询默认最多等待 3 秒，尚未完成会提示稍后重试，后台继续查询。

## ✨ 功能特性

- 🎮 **状态一览** - 展示服务器名称、游戏模式、地图、模块和在线人数。
- 🏷️ **灵活查询** - 支持完整名称、简称、端口号，以及无空格的「查服CN_X1」。
- 🔍 **在线发现** - 寻找尚未收录的服务器，精确目标命中后即可回复。
- ⚡ **快速返回** - 后台刷新常用服务器，多人查询共享探测结果。
- 🔧 **固定直查** - 已知端点可独立刷新，官方列表暂不可达时仍能查询。
- 💾 **重启恢复** - 保存已知地址与上次结果，重载后自动预热。
- 🔒 **权限可控** - 群聊、私聊独立开关，支持群号和用户白名单。

## 📦 安装

需要 **AstrBot `>=4.17.0,<5`**，通过 `aiocqhttp`（OneBot 11）适配器接入 QQ。插件使用 Python 标准库，无需额外安装第三方依赖。

1. 从[本仓库](https://github.com/fanqiecd/astrbot_plugin_warband_status)下载完整源码。
2. 将插件文件夹命名为 `astrbot_plugin_warband_status`，放入 AstrBot 的 `data/plugins/` 目录。确认文件夹根层包含 `main.py`、`warband_net.py`、`warband_service.py` 和 `metadata.yaml`，不要多嵌套一层目录。
3. 在 AstrBot WebUI 的插件管理中加载并启用插件；更新已有插件后执行重载。

默认配置即可查询内置服务器。要添加自己的服务器，在插件配置中填写 `extra_endpoints`。

## 🚀 使用方法

在群里发送 **`查服`** 即可查询默认列表；也可以 @机器人或使用 AstrBot 配置的唤醒前缀调用指令。

- **查询默认列表**：`查服`、`查服 全部`、`查服 all`
- **查询某台服务器**：`查服 X1`、`查服 CN_X3_GK`、`查服 GK`
- **搜索未收录的服务器**：`查服 CN_Swiss_02`、`查服 CN_Vinland`
- **按已知端口或端点查询**：`查服 7240`、`查服 106.54.62.240:7240`
- **不加空格查询**：`查服CN_X1`
- **@机器人调用**：`@机器人 查服 X1`、`@机器人CN_X1`
- **使用唤醒前缀**：`/查服 X1`（以 `/` 为唤醒前缀时）

还支持「查询服务器」「服务器状态」「骑砍服务器」「骑砍状态」作为指令别名。私聊或已唤醒时，按 AstrBot 的指令方式调用；关闭 `enable_keyword` 后，群里不唤醒机器人的直接关键字查询不再响应。

**「全部」的范围**是配置的服务器、固定端点，以及已发现的 `CN_X` 系列，按配置顺序优先展示。端口和端点查询只匹配已配置或已发现的地址；匹配到多个服务器时，会提示使用完整名称或端点区分。

### 💡 回复示例

以下为格式示例，人数、地图和模式以服务器返回为准。

**输入：** 查服 X1

**回复：**

```text
服务器名称：CN_X1
游戏模式：战场模式
当前地图：The Cage
当前模块：Native
在线人数：48/200
```

查询多台服务器时，每台一段，用横线分隔。

### 🕒 如何理解查询状态

- **正常显示人数、地图等字段**：返回当前可用的缓存结果。
- **「上次结果」并附数据时间**：数据较旧、刚从磁盘恢复，或最近一次探测失败；后台正在更新。
- **「暂无结果」或「正在查询」**：尚未拿到结果，稍后重试即可。
- **「近期无响应」**：多次探测失败或数据已超过有效期限，不能据此确认服务器已经关服。
- **「暂未定位到」**：部分端点或主列表无响应，暂时无法确定目标。

默认数据超过 60 秒会标记为上次结果，超过 5 分钟或连续 3 次失败后显示近期无响应。调整 `max_cache_age` 后，失效期限为 `max(300, max_cache_age × 5)` 秒。

首次查询的 3 秒是插件等待结果的预算；实际收到消息的时间还受 AstrBot 调度和消息平台影响。查询超时后不会自动追加消息，需要稍后再次查询。

## ⚙️ 配置项说明

在 AstrBot WebUI 的插件配置页修改，保存后重载生效。

### 服务器与访问权限

- `servers` — 默认列表中的服务器名称及顺序；留空回退到内置列表。默认：`CN_X1`、`CN_X3_GK`、`CN_X4`
- `extra_endpoints` — 固定直查的 IPv4 地址与端口。默认：`106.54.62.240:7240`、`106.54.62.240:7242`
- `seed_hosts` — 在主列表中优先查找端口的主机 IP。默认：`116.62.36.206`
- `exclude_servers` — 隐藏、不返回状态的服务器名称。默认：`CN_X4_zuikuai`
- `show_offline` — 全部查询中是否显示近期无响应的条目；单台查询始终说明状态。默认：`true`
- `discovery_enabled` — 是否允许按未知名称在线搜索。默认：`true`
- `enable_keyword` — 是否响应未唤醒时的直接关键字查询。默认：`true`
- `enable_group` — 是否响应群聊查询。默认：`true`
- `enable_private` — 是否响应私聊查询。默认：`true`
- `group_whitelist` — 允许查询的群号；空列表表示不限群号
- `user_whitelist` — 允许查询的用户 ID；空列表表示不限用户

群号白名单仅用于群聊，用户白名单同时用于群聊和私聊。固定端点示例 `106.54.62.240:7240` 中，冒号前是 IPv4 地址，后面是端口。

### 刷新与等待时间

- `refresh_interval` — 常用服务器状态刷新间隔，单位秒。默认：`45`
- `max_cache_age` — 单台缓存标记为上次结果的年龄阈值，单位秒。默认：`60`
- `probe_timeout` — 单台连接与读取共用的总超时，单位秒。默认：`4`
- `query_wait_timeout` — 首次或未知查询的前台等待预算，单位秒。默认：`3`
- `master_refresh_interval` — 官方地址列表刷新间隔，单位秒。默认：`180`
- `max_probe` — 每轮后台抽样探测的最大数量。默认：`60`
- `probe_concurrency` — 刷新与发现共享的探测并发上限。默认：`32`
- `master_url` — 官方地址列表接口，通常无需修改

希望人数更新更及时，可将 `refresh_interval` 调为 **15～30 秒**。`master_refresh_interval` 只影响地址列表更新，固定和已知端点不必等待它。提高并发或缩短探测超时不一定更快，也可能增加无响应结果。

列表类配置最多读取前 256 项；各数值的有效范围可在 WebUI 配置提示中查看。

## 🔗 数据来源与反馈

- [TaleWorlds 官方战团主服务器列表](https://warbandmain.taleworlds.com/handlerservers.ashx?type=list)提供服务器地址。
- 名称、模式、地图、模块和人数来自各服务器返回的 `ServerStats`。
- 默认 CN_X 系列来自[骑马与砍杀中文站](https://bbs.mountblade.com.cn)。

地图和模式由服务器自行上报，换图时可能短暂出现异常字段。反馈问题时，可附上查询指令、配置中的相关项和错误日志；请去除群号、用户 ID 等个人信息。

# 🛡️ 骑砍战团服务器查询

<i>一个 AstrBot 插件：随时查询骑马与砍杀：战团联机服务器的在线人数、模式、地图与模块。</i>

</div>

---

## 📖 简介

为 QQ 群 / 私聊机器人提供**战团联机服务器状态查询**：内置骑砍中文站 CN_X 系列（`CN_X1`、`CN_X3_GK`、`CN_X4`），并支持固定端点直查（默认 `CN_YJMD_X1/X2` 所在的 `106.54.62.240:7240/7242`）。

插件在后台定时抓取 TaleWorlds 官方主服务器列表并对目标服务器做 TCP 探测，结果缓存在内存中——收到查询**优先读缓存**，热缓存毫秒级返回，冷启动首次查询约 1~3 秒。

---

## ✨ 功能特性

- ⚡ **秒回** - 后台定时刷新 + 内存缓存，查询基本即时返回
- 🎮 **逐台详情** - 每台服务器输出名称、游戏模式、当前地图、模块、在线人数（当前/上限）
- 🏷️ **两种调用** - 支持唤醒前缀指令（`查服 X1`），也支持直接发关键字（`查服`）触发
- 🎯 **灵活目标** - 支持全名/简称/别名/端口号，如 `CN_X3_GK`、`X3`、`GK`、`7240`
- 🔧 **固定端点直查** - 不依赖主服务器列表，始终探测你指定的 `ip:port`
- 🧭 **自动发现** - 后台抽样扫描，中文站 CN_X 系列更换主机后也能自动找到（不想要的可用 `exclude_servers` 排除）
- 🔒 **权限可控** - 群聊/私聊独立开关，群号/用户双白名单
- 📦 **零依赖** - 纯 Python 标准库 + asyncio，无需额外安装第三方包

---

## 📦 安装

将 `astrbot_plugin_warband_status` 整个目录放入 AstrBot 的插件目录，然后在 WebUI「插件管理」中重载并启用：

```bash
# 以 AstrBot 的 data/plugins 目录为例
cp -r astrbot_plugin_warband_status /path/to/AstrBot/data/plugins/
```

要求：AstrBot `>= 4.17`，支持平台：`aiocqhttp`（OneBot 11 协议端）。

---

## 🚀 使用方法

最短路：在群里**直接发送**关键字，或**@机器人 / 加唤醒前缀**后发指令，不带参数即查询全部。

| 调用方式 | 示例 |
| :--- | :--- |
| 指令（@ / 唤醒前缀） | `@机器人 查服`、`/查服 X1`、`/查服 CN_YJMD_X2` |
| 关键字（直接发送） | `查服`、`查服 X3`、`服务器状态`、`骑砍服务器` |
| 查全部 | `查服 全部` / `查服 all`（不带参数默认全部） |

### 💡 示例

> **输入：** `查服 X1`
>
> **输出：**
>
> ```
> 服务器名称：CN_X1
> 游戏模式：战场模式
> 当前地图：The Cage
> 当前模块：Native
> 在线人数：48/200
> ```

> **输入：** `查服 全部`
>
> **输出：** 每台目标服务器一段，段间用一行横线分隔（未开机的服务器会显示「未在线」）：
>
> ```
> 服务器名称：CN_YJMD_X1
> 游戏模式：入侵模式
> 当前地图：峡谷
> 当前模块：Native
> 在线人数：0/12
> ---------------------------------
> 服务器名称：106.54.62.240:7240
> 状态：未在线（服务器无响应或未开服）
> ```

## ⚙️ 配置项说明

在 WebUI 插件配置页可修改，以下为默认值：

| 配置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `enable_group` | 是否响应群聊查询 | `true` |
| `enable_private` | 是否响应私聊查询 | `true` |
| `group_whitelist` | 允许的群号白名单，空=所有群 | `[]` |
| `user_whitelist` | 允许的用户 ID 白名单，空=所有用户 | `[]` |
| `enable_keyword` | 是否允许直接发关键字触发 | `true` |
| `servers` | 默认查询的服务器及顺序 | `["CN_X1", "CN_X3_GK", "CN_X4"]` |
| `exclude_servers` | 隐藏、不参与查询展示的服务器名 | `["CN_X4_zuikuai"]` |
| `extra_endpoints` | 固定直查端点（`ip:port`），每轮直接探测 | `["106.54.62.240:7240", "106.54.62.240:7242"]` |
| `seed_hosts` | 中文站 CN_X 系列所在主机 IP | `["116.62.36.206"]` |
| `show_offline` | 全量查询时是否展示未在线服务器 | `true` |
| `refresh_interval` | 后台刷新间隔（秒） | `45` |
| `max_cache_age` | 回复允许的缓存最大年龄（秒），超龄先刷新 | `60` |
| `probe_timeout` | 单台服务器查询超时（秒） | `4` |
| `max_probe` | 每轮后台抽样探测的最大服务器数 | `60` |
| `master_url` | TaleWorlds 官方主服务器列表地址 | `https://warbandmain.taleworlds.com/handlerservers.ashx?type=list` |

## 🔗 数据来源

- [TaleWorlds 战团主服务器列表](https://warbandmain.taleworlds.com/handlerservers.ashx?type=list)（在线服务器列表）
- 各服务器直连返回的 `<ServerStats>` 信息（名称/模式/地图/模块/人数）
- CN_X 系列为[骑马与砍杀中文站](https://bbs.mountblade.com.cn)官方联机服务器

> 提示：当前地图/游戏模式为服务器自身上报内容，换图间隙可能出现短暂异常值（如 CN_X1 把地图字段报成「战场模式」），属服务器行为而非插件错误。
